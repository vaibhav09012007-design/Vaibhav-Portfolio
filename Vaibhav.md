### 2. Aria — AI Document Intelligence Platform
**Status:** 🟡 In Development
**Stack:** FastAPI · Next.js · LangChain · ChromaDB · Celery · Redis · WebSocket
**GitHub:** [github.com/Vaibhavtiwari-dev/ARIA-](https://github.com/Vaibhavtiwari-dev/ARIA-)

Production-grade RAG pipeline for document Q&A with cited answers. Designed for real latency targets, not just demos.

**Key highlights:**
- Designed a production RAG pipeline — document ingestion, async processing via Celery + Redis, vector search with ChromaDB, and streaming WebSocket responses with sub-800ms first-token latency.
- Built semantic search with citation tracking — each answer references exact source documents with page-level granularity using a custom `[CITE:doc_id:chunk_id]` parsing system.
- Engineered multi-format document processing (PDF, CSV, XLSX, DOCX) with RecursiveCharacterTextSplitter (512 tokens, 64 overlap) and batch embedding via Google text-embedding-004.
